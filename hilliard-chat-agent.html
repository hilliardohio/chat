Customize responses by topic

When a resident's question matches a topic's keywords, your customization kicks in. Guide the AI adds your instructions to the AI's answer (it still writes naturally). Fixed answer returns your exact text instantly, without calling the AI. Topics can be turned off without deleting them.

Claude API connection

This prototype calls the Claude API directly from the browser. Get a key at console.anthropic.com → API Keys. The key is stored only in this browser (localStorage) — for a public deployment, move the API call behind a small server so the key is never exposed.
